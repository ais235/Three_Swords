# Three Blades — топология мировой карты

Дата фиксации: 2026-07-28. Версия раскладки: 2.

## Замысел

Карта сохраняет локальные развилки внутри каждого региона, но переходы между регионами образуют змейку:

1. Регион 1 проходится слева направо.
2. После босса переход в регион 2 находится справа.
3. Регион 2 проходится справа налево.
4. После босса переход в регион 3 находится слева.
5. Регион 3 проходится слева направо к региональному и финальному боссам.

## Фиксированные точки

| Объект | Координата |
|---|---:|
| Старт | `(0, 0)` |
| Босс региона 1 | `(11, 1)` |
| Переход 1 → 2 | `(11, 2)` → `(11, 3)` |
| Босс региона 2 | `(0, 4)` |
| Переход 2 → 3 | `(0, 5)` → `(0, 6)` |
| Босс региона 3 | `(11, 6)` |
| Финальный босс | `(11, 7)` |

Остальные миссии, города, события, подземелья и арены продолжают распределяться по seed.

## Правила стен

- Граница между строками 2 и 3 закрыта во всех колонках, кроме `x = 11`.
- Граница между строками 5 и 6 закрыта во всех колонках, кроме `x = 0`.
- Диагональное пересечение стены запрещено.
- Победа над боссом по-прежнему открывает следующий регион.
- Старые сохранения переносят незавершённых и завершённых боссов в новые точки без сброса героев, предметов и статистики кампании.

Чистая логика находится в `src/map-topology.js`. Проверка `npm run test:map` подтверждает расположение боссов, два допустимых прохода, отсутствие диагонального обхода и достижимость всех 96 клеток.
