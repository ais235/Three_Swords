# Системы: бой, характеристики, статусы, экономика

## Характеристики юнита (общие)

- **hp / maxHp** — здоровье.
- **armor** — вычитается из входящего урона (до минимума 0), с модификаторами (пробитие, тайл, способности врагов/героев).
- **attack** — базовый урон атаки.
- **range** — дальность атаки в клетках (манхэттен); для дальнобоя учитывается **линия обзора** (`rangedBlocked`) и лес/укрытие, если нет перка `ignoreCover`.
- **move** — очки передвижения за ход (с учётом стоимости тайла `tileMoveCost`).
- **speed** — участвует в построении **инициативы** (`buildInitiative`).

У героев в бою дополнительно: `mana`/`maxMana` (маг), `cds` (кулдауны умений), `perks` (строковые id перков), `flags`, `activeStatuses`.

## Порядок хода и раунды

- Очередь `order` — индексы юнитов в `units`.
- Смена активного юнита: `advanceSingleTurn`; при обходе всей очереди — новый **рауннд**, сброс `firstAttackTurn` у героев, тик глобального `watcherDeadMove` если задан.

## Статусы (`STATUS`)

Типы: `stun`, `freeze`, `web`, `poison`, `burn`, `slow`, `blind`, `curse`, `berserk`, `stealth`.

- **Яд / огонь** (`poison`, `burn`): урон в начале хода (например −3), длительность уменьшается по своей логике в `tickStatusesStart` / `tickStatusesEndTurn`.
- **stun, freeze, slow, web, blind, curse, berserk**: длительность в ходах, часть снимается в `tickStatusesEndTurn`.

Особые эффекты в бою:

- **Слепота** — мешает атаковать по клику до снятия.
- **Берсерк** (герой Гарет) — удваивает исходящий урон, снижает броню.

## Урон (`dealDamage`)

Упрощённо: сырой урон минус (броня цели + бонус защиты тайла), затем особые случаи:

- Гарет: `fireCallMitigateActive`, щитовой блок (шанс), перк `armorPierce`, реакция на `BERSERK`.
- Алира: бонус урона на **первую атаку за раунд** (`firstAttackTurn`).
- Сэрис: **mysticShield** поглощает часть урона (заряды).
- **Призрак**: физические атаки героев-воина/лучника без флага `magic` наносят **0**; магические — проходят.
- **Тёмный Лорд в фазе 3**: для не-мага без магии/артефакта физический урон с героя может обнуляться (см. код `dealDamage`).
- **Ледяной элементаль**: урон с флагом `fire` усилен ×1.5.
- **Орк-страж** как атакующий: у цели эффективная броня уменьшается на 2 (`ignoreOrc` отключает для особых случаев).

## Тайлы и огонь

- Клетка `FIRE`: в `applyGroundEffects` стоящий юнит получает **−3 HP** в подходящий момент хода.
- Титан поджигает случайные клетки каждый свой ход.

## Золото и награды за бой

- Базовый диапазон золота зависит от типа клетки (`dungeon` выше обычного), босс/финал — фиксированные или увеличенные суммы.
- За убийство врагов в бою начисляется золото по диапазону `gold` из `enemyDef` (логика в наградах боя — см. код `applyBattleRewards` / победа).

## Опыт после победы

- Каждому **живому** герою: `xpEach = 20 + region * 10`.
- Уровень растёт пока `xp >= level * 40` и `level < 8`; при повышении уровня в `pendingPerks` добавляется id героя для выбора ветки перка.

## Инвентарь и магазин

- **SHOP_ITEMS** — расходники (зелье HP, эликсир маны, камень магии).
- **ITEM_POOL** — оружие, броня, артефакты с `mods` (атака, броня, дальность, `poisonOnHit`, `stunOnHit`, `aoePlus`, `ignoreCover`, `dodge`, `reflectDmg`, `revive5`, и др.).

## Глобальные бафы боя

- `globalBuffs.watcherDeadMove`: если **Следящий** убит, несколько раундов у **всех живых врагов** в `getSpeed` добавляется **+1 к скорости** (очередь ходов / инициатива), не к очкам передвижения за ход.
