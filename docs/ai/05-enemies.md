# Враги: идентификаторы, статы, волны, способности

Идентификаторы заданы в `ENEMY_IDS`; статы — в `enemyDef(type)`. Волны по регионам — `generateEnemyWaveForCell`.

## Соответствие имён (код ↔ ассеты)

| Код (`enemyId`) | Примечание |
|-----------------|------------|
| `suicide` | Подрывник; в файлах спрайтов может быть `bomber.png` |
| `ice_elem` | Ледяной элементаль (не `ice_elemental`) |
| `necro` | Некромант |

## Пулы волн по региону (`generateEnemyWaveForCell`)

- **Регион 1**: skeleton, goblin_archer, boar, zombie, shaman.
- **Регион 2**: orc_guard, spider, suicide, ice_elem, watcher, dark_knight.
- **Регион 3**: necro, chaos, assassin, hydra, ghost.

Размер волны: обычная клетка **3** юнита; `dungeon` — **4**; `arena` — **1**.

### Босс-узлы

- Тип `boss`: регион **2** → только `fire_titan`; иначе → `dark_knight`.
- Тип `final` → один `dark_lord`.

## Поведение и способности (по коду)

### Общее

- **Следящий жив**: все вражеские атаки получают **+2** к урону (`findWatcher` + `aiAttack`).
- **Следящий убит**: `globalBuffs.watcherDeadMove = 2` — несколько раундов у врагов **+1 к speed** при пересчёте инициативы (чаще ходят раньше).

### Отдельные типы

| Враг | Поведение |
|------|-----------|
| **skeleton** | Обычный ИИ: движение к герою, атака в радиусе. |
| **goblin_archer** | Если герой **в соседней** клетке — сначала **отступает** на шаг, иначе стандартное движение/стрельба. |
| **boar** | В UI: «Рывок к цели»; отдельного кода рывка под id `boar` в `runEnemyTurn` **нет** — движение как у обычного ближника. |
| **zombie** | При смерти: **5 магического урона** соседним героям (манхэттен ≤1), `blockIgnore: true`. |
| **shaman** | Каждые ~2 хода лечит союзника с минимальным %HP на **30% от maxHp** (один раз за срабатывание), затем пропускает стандартный ход в этот момент. |
| **orc_guard** | При атаке **игнорирует 2 брони** цели. |
| **suicide** | Идёт к ближайшему герою; если рядом (≤1) — **взрыв**: 20 урона соседним героям, `blockIgnore: true`, сам уничтожается. |
| **spider** | После каждого попадания атакой накладывает **WEB** на 2 хода. |
| **watcher** | Не получает отдельного AI-скрипта кроме общего; `range: 0` — атака только если уже вплотную (редко); основная угроза — **баф урона** союзникам. |
| **ice_elem** | Дальний бой; при попадании — **FREEZE** на 1 ход. Уязвим к **огню** (×1.5). |
| **dark_knight** | Сильный мини-босс, обычный ИИ. |
| **necro** | Обычный дальнобойный ИИ (**нет** призыва скелетов в текущем коде). |
| **chaos** | Стоит (`move: 0`), бьёт в радиусе 2; `bossVar.aoeTurn` **не используется**. |
| **assassin** | Визуально **невидим** в лесу или рядом с горами; урон ×2 по герою, если убийца стоит **за спиной** (соседняя клетка с противоположной стороны). |
| **hydra** | Одна атака = **три** последовательных удара по цели; каждый может наложить **POISON** на 2 хода. |
| **ghost** | Атака считается **магической**; физика воина/лучника не пробивает; проходит **сквозь горы** при движении. |
| **fire_titan** | Каждый ход: случайные клетки → **FIRE** (2 или 4 если HP < 50%); каждый 3-й ход — **AoE** вокруг себя (крест + центр): 10 огненного магического урона по героям; затем движение/удар по приоритетной цели. |
| **dark_lord** | **Фазовый босс** (`darkLordAi`): **Фаза 1** — пассивен, пока живы призванные **orc_guard** (до 4 в начале боя); **Фаза 2** — телепорт каждые 2 хода, удар рядом, каждые 3 хода AoE по героям в ринге на расстоянии 1 (12 маг урона + BLIND), каждые 4 хода призыв скелетов; при HP ≤80 → **Фаза 3** — сильнее базовая атака в `aiAttack`, случайный герой получает **CURSE** на 2 хода; в фазе 3 у Лорда особые правила получения урона от не-магов (см. `dealDamage`). |

## Тексты подсказок UI (`enemyAbilityText`)

Краткие строки для тултипа: скелет — обычная атака; гоблин — отступает; кабан — рывок (лор); зомби — взрыв при смерти; шаман — лечит; орк — тяжёлая броня; подрывник — самоподрыв; паук — паутина; следящий — усиление союзников; лёд — морозит; тёмный лорд — фазовый босс. Для остальных — «Опасный противник.»

---

## Гидра: головы

При спавне: `heads: 3`, `headHp: 10` — используется в логике многократного удара; точное отсечение голов в HP может отличаться от визуала; сверять с функциями урона по гидре в коде при доработках.
