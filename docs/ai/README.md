# Документация для ИИ (контекст проекта «Три Героя»)

Эти файлы описывают игру **как она реализована** в репозитории (`index.html`), чтобы другой ИИ или разработчик мог быстро войти в контекст без чтения всего кода.

## Порядок чтения

| Файл | Содержание |
|------|------------|
| [00-game-overview.md](00-game-overview.md) | Краткое игровое описание, жанр, цикл игры, три героя |
| [01-technical-architecture.md](01-technical-architecture.md) | Стек, структура кода, константы, сохранение, карта мира |
| [02-systems-combat-and-stats.md](02-systems-combat-and-stats.md) | Бой, характеристики, статусы, тайлы, золото/награды |
| [03-heroes-and-skills.md](03-heroes-and-skills.md) | Герои, умения, опыт и уровни |
| [04-perk-trees.md](04-perk-trees.md) | Деревья развития (перки) по веткам |
| [05-enemies.md](05-enemies.md) | Все типы врагов: статы, волны по регионам, ИИ и способности |

## Важно для ИИ

- **Источник истины** — логика в `index.html` (один крупный файл). Если документ расходится с кодом, приоритет у кода.
- Идентификатор подрывника в коде: `suicide` (в ассетах может использоваться имя `bomber.png`).
- У хаос-демона (`chaos`) в спавне есть поле `bossVar.aoeTurn`, но в текущей версии оно **не используется** в логике боя — см. технический файл.
