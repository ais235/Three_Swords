# Герои, умения и прогрессия

## Стартовые шаблоны (`baseHeroTemplate`)

### Гарет (`garet`) — воин

- Роль: `warrior`.
- Старт: hp 40, armor 5, attack 8, range 1, move 3, speed 10, level 1, mana 0.
- Умения (кулдауны в `cds`): **Удар щитом** (`shieldBash`), **Вызов огня** (`fireCall`), **Берсерк** (`berserk`).

**Удар щитом**: цель в соседней клетке; атака + **stun** на 1 ход; кулдаун 3.

**Вызов огня**: по врагам в радиусе манхэттена ≤2 от Гарета наносится урон от их собственной атаки (половина, минимум 1), игнорируя блок; Гарет получает флаг смягчения входящего урона на время; кулдаун 4.

**Берсерк**: накладывает на себя `BERSERK` на 3 хода, броня режется примерно вдвое (floor); кулдаун 6.

### Алира (`alira`) — лучник

- Роль: `archer`.
- Старт: hp 25, armor 2, attack 10, range 4, move 4, speed 11.
- Умения: **Двойной выстрел** (`doubleShot`), **Стрела замедления** (`slowArrow`), **Дождь стрел** (`arrowRain`).

**Двойной выстрел**: две обычные атаки по одной цели; кулдаун 2.

**Стрела замедления**: урон + `SLOW` на 2 хода; кулдаун 3.

**Дождь стрел**: урон по всем врагам в квадрате 3×3 вокруг Алиры (смещение ±1); кулдаун 5.

### Сэрис (`seris`) — маг

- Роль: `mage`.
- Старт: hp 20, armor 1, attack 12, range 3, move 3, speed 9, mana 10/10.
- Флаг `mysticShield: 3` — заряды поглощения.
- Умения: **Огненный шар** (3 MP), **Заморозка** (4 MP), **Метеорит** (8 MP).

**Огненный шар**: 15 магического огненного урона по цели в радиусе + 7 по соседним врагам; кулдаун 2.

**Заморозка**: `FREEZE` на цель на 1 ход; кулдаун 3.

**Метеорит**: область 2×2 от точки клика, 30 огненного магического урона по врагам в области; кулдаун 6.

## Боевые юниты героев

`makeBattleHero` клонирует состояние из `GameState.heroes`, выставляет позицию, копирует кулдауны, переносит `perks` и флаги, добавляет `activeStatuses`. Скорость в бою может слегка корректироваться по роли.

## Уровни и перки

- Максимальный уровень героя в коде: **8**.
- Порог опыта на уровень: **`level * 40`** (накопительно вычитается в цикле `while`).
- При level up герой попадает в `GameState.pendingPerks` — игрок выбирает **одну ветку** и **один перк** из доступных по уровню (см. `04-perk-trees.md`).

## Синхронизация после боя

`syncHeroFromUnit` переносит в persistent-героя: hp, mana, cds, статусы, флаги с боевого юнита.
