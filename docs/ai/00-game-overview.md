# Описание игры (обзор)

## Название и жанр

**«Три Героя»** (`Три Героя — Three Heroes`) — пошаговая тактическая игра в браузере: отряд из трёх героев исследует карту мира **12×8** клеток, сражается на изометрической сетке боя **12×8**, получает золото, предметы, опыт и открывает перки.

## Три героя

1. **Гарет** — воин (ближний бой, щит, выносливость).
2. **Алира** — лучник (дальний бой, мобильность).
3. **Сэрис** — маг (мана, магический урон, контроль).

У каждого свой набор активных умений с перезарядкой; у мага есть **мана** и мистический щит (заряды поглощения урона).

## Цикл игры

1. **Карта мира** — узлы типов: миссия, город, подземелье, событие, босс, странник, арена, финал. Регионы **1–3** (верхние две строки сетки — регион 1, средние — 2, нижние — 3).
2. **Бой** — фаза расстановки (герои в первых двух колонках), затем бой по **инициативе** (очередь ходов). Герой за ход может двигаться и атаковать/использовать умение (в зависимости от UI и режима).
3. **После победы** — золото, опыт всем выжившим героям, при достижении порога опыта — **выбор перка** из дерева героя.
4. **Город** — магазин расходников и экипировки; события на карте дают случайные эффекты или бои.

## Сеттинг (из контента)

Фэнтези: скелеты, гоблины, орки, нежить, элементали, демоны, финальный противник **Тёмный Лорд**. Визуально враги могут отображаться эмодзи и/или спрайтами из `assets/enemies/`.

## Цель игрока

Продвигаться по карте, побеждать энкаунтеры, победить боссов регионов и в итоге **финальный узел** с Тёмным Лордом. Победа над боссом региона повышает `regionUnlocked` (до 3).
