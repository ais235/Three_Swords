# Система баланса Three Blades

## Философия баланса

**Три столпа:**
1. **Герои слабеют и крепнут вместе** — нельзя качать одного. Враги масштабируются с общей силой отряда.
2. **Лут мотивирует** — каждый предмет ощутимо улучшает или открывает новую стратегию.
3. **Прогрессия гладкая** — нет скачков сложности, платоу, или грайндинга.

---

## Метрика силы отряда (`partyPower`)

Единая число, на которой вся система расчитана.

```javascript
function calculatePartyPower() {
  return heroes.reduce((sum, h) => {
    const heroPower = h.attack + h.armor + h.maxHp / 10 + h.range + h.speed / 2;
    return sum + heroPower;
  }, 0);
}
```

**Примеры:**
- Гарет: 8 + 5 + 4 + 1 + 5 = 23
- Алира: 10 + 2 + 2.5 + 4 + 5.5 = 24
- Сэрис: 12 + 1 + 2 + 3 + 4.5 = 22.5
- **Стартовый party power = ~70**

Эта метрика используется в `enemyDef`, масштабировании награды, лига боссов и подборе лута.

### Скейлинг врага под partyPower

При спавне волны враг масштабируется:

```javascript
function scaleEnemy(enemyBase, partyPower, region) {
  const baseScale = partyPower / 70; // 70 = стартовое значение
  const regionBonus = 1 + (region - 1) * 0.15; // Регион 2 +15%, Регион 3 +30%
  const finalScale = Math.max(1, baseScale * regionBonus);

  return {
    ...enemyBase,
    hp: Math.round(enemyBase.hp * finalScale),
    attack: Math.round(enemyBase.attack * finalScale * 0.8), // атак меньше, чем HP
    armor: Math.round(enemyBase.armor * finalScale * 0.6),
    range: enemyBase.range, // дальность не скейлится
    move: enemyBase.move // движение не скейлится
  };
}
```

**Примеры:**
- Враг skeleton при party power 70 (стартово): HP 8 × 1 = 8, ATK 5 × 0.8 = 4
- Враг skeleton при party power 140 (дошли до Региона 2): HP 8 × 2 = 16, ATK 5 × 1.6 × 0.8 = 6.4 ≈ 6
- Враг shaman в Регион 1 (power 70): HP 25, ATK 5 × 0.8 = 4
- Враг shaman в Регион 2 (power 100): HP 25 × (100/70) × 1.15 ≈ 41, ATK 5 × (100/70) × 1.15 × 0.8 ≈ 6.6 ≈ 7

## Прокачка героев: перки и ветки

**Стартово:** все герои уровень 1.

**Уровни:** 1–8 (максимум).

**Опыт за уровень:** 40 × уровень (кумулятивно).
- До уровня 2: нужно 40 опыта
- До уровня 3: нужно 80 опыта
- До уровня 8: нужно 280 опыта

**За бой дают:**
- Обычная миссия: 20 опыта
- Подземелье: 40 опыта
- Мини-босс: 50 опыта
- Босс региона: 80 опыта
- Тёмный Лорд: 100 опыта

**Формула:**
```javascript
xpForBattle = baseXp + (region - 1) * 10 + (bossLevel * 20);
// где bossLevel: 0 = обычный, 1 = мини-босс, 2 = босс региона, 3 = финал
```

**При level up:**
- Герой получает в меню выбора **две ветки из трёх**
- Игрок выбирает одну ветку → открывает перк уровня 1 этой ветки
- Следующий level up можно развить ту же ветку (уровень 2) или переключиться
- **Цель:** к уровню 8 герой имеет ~3–4 перка, из них 2–3 одной ветки

## Перки: эффект и баланс

### Гарет (Воин)

**Защита (D1–D3):**
- D1 (+5 HP): `maxHp += 5`. **Когда взять:** если часто ломают героя.
- D2 (+1 броня): `armor += 1`. **Каскад:** 5 + 6 + 7 брони = хороший танк.
- D3 (Отражение 1): перк `reflect1` — враг получает 1 урона при попадании.

**Атака (A1–A3):**
- A1 (+2 атака): `attack += 2`.
- A2 (Пробивание): враг получает −2 брони от атак.
- A3 (Крит 15%): шанс критического удара × 1.5 урона.

**Лидер (L1–L3):**
- L1 (Аура брони): соседи +1 броня (радиус 1 клетка).
- L2 (Аура урона): соседи +10% урона.
- L3 (Командир): `speed += 1`, ходит раньше.

**Рекомендуемый путь:**
- Рано (уровни 2–4): Защита (выживание) + немного Атаки (D1, A1).
- Середина (уровни 4–6): Атака доделать (A2, A3) или Лидер (L1).
- Поздно (6–8): если есть Лидер L1 — качать L2, L3 (отряд станет сильнее вместе).

---

### Алира (Лучник)

**Меткость (M1–M3):**
- M1 (+1 дальность): `range += 1`. Теперь может бить издалека.
- M2 (+3 атака): `attack += 3`.
- M3 (Игнор укрытия): лес и гоблины не блокируют.

**Скорость (S1–S3):**
- S1 (+1 движение): `move += 1`, 5 клеток за ход.
- S2 (Выстрел после шага): после движения можно атаковать без штрафа.
- S3 (+2 скорость): `speed += 2`, ходит первой.

**Ловушки (T1–T3):**
- T1 (Ловушка урон): перк `trapDmg` — уроны 10 врагу при наступлении.
- T2 (Ловушка замедление): враг −2 движения на 2 хода.
- T3 (Двойные ловушки): ставит 2 ловушки за ход вместо 1.

**Рекомендуемый путь:**
- Рано (2–4): Скорость (S1) — ходит раньше, может убежать. Меткость (M1) для дальности.
- Середина (4–6): M2, M3 для урона через преграды.
- Поздно (6–8): S2 для комбо шаг+выстрел или T1–T3 для контроля (ловушки).

---

### Сэрис (Маг)

**Разрушение (R1–R3):**
- R1 (+3 магический урон): `attack += 3`.
- R2 (AoE +1): все заклинания область +1 радиус (вместо 1 клетки — 2 клетки).
- R3 (Сжигание): заклинания накладывают BURN на 2 хода, −3 HP/ход.

**Контроль (C1–C3):**
- C1 (Фриз 2 хода): Заморозка держит врага 2 хода вместо 1.
- C2 (Страх): новое заклинание или модификация — враг убегает 1 ход.
- C3 (Мастер контроля): `maxMana += 2`, можно использовать заклинания чаще.

**Мистика (Y1–Y3):**
- Y1 (+3 макс мана): `maxMana += 3`, было 10 → 13.
- Y2 (HP за убийство): при убийстве врага маг восстанавливает 5 HP.
- Y3 (Телепорт): один раз за бой телепортируется на любую видимую клетку (6 маны).

**Рекомендуемый путь:**
- Рано (2–4): Мистика (Y1) — больше маны для заклинаний.
- Середина (4–6): Контроль (C1, C2) для фриза/страха врагов.
- Поздно (6–8): Разрушение (R1, R2) для массового урона или Мистика (Y2, Y3) для выживания и мобильности.

## Лут: предметы и редкость

### Редкость и выпадение

```
Обычный (Common):   белый/серый
Редкий (Rare):      синий
Эпический (Epic):   жёлтый/золотой
```

**Вероятность выпадения при убийстве врага:**
- Обычный враг (skeleton, goblin): 30% chance + основное золото
- Сильный враг (boar, spider, ice_elem): 50% chance
- Мини-босс (shaman, dark_knight): 80% chance + гарантированный rare
- Босс региона (fire_titan): 100% chance + гарантированный epic
- Финал (dark_lord): 100% epic + 1 случайный artifact

**Как выпадает:**
```javascript
function rollLootOnEnemyDeath(enemy, partyPower) {
  const lootRoll = Math.random();
  if (lootRoll < enemy.lootChance) {
    const item = selectLootItem(partyPower, enemy.region);
    GameState.inventory.push(item);
    battleLog(`Враг выронил: ${item.name}`);
  }
}
```

### Экономика лута

**Цель:** игрок находит лучше предметы через каждые **3–4 боя**, ощущает прогресс.

Логика распределения:

```javascript
function selectLootItem(partyPower, region) {
  const commonPool = ITEM_POOL.filter(i => i.rarity === 'common');
  const rarePool = ITEM_POOL.filter(i => i.rarity === 'rare' && i.region <= region);
  const epicPool = ITEM_POOL.filter(i => i.rarity === 'epic' && i.region <= region);

  let targetPool = commonPool;
  let rarity = 'common';

  // Чем дальше в игре, тем выше вероятность лучшего лута
  const regionChance = (region - 1) * 0.2; // Р1: 0%, Р2: 20%, Р3: 40%
  const roll = Math.random();

  if (roll < 0.1 + regionChance) {
    targetPool = epicPool;
    rarity = 'epic';
  } else if (roll < 0.3 + regionChance * 0.5) {
    targetPool = rarePool;
    rarity = 'rare';
  }

  return selectRandomFromPool(targetPool);
}
```

**Типичный прогресс:**
- **Регион 1 (ходы 1–15):** начинают со стартовых 35g, находят 1–2 обычных предмета, покупают Охотничий лук Алире (40g), Плащ воина (30g).
- **Переход Р1→Р2 (ход 16):** 150g накопилось, в награду за босса Р1 — rare предмет. Покупают Rare боевое оружие у торговца.
- **Регион 2 (ходы 17–35):** находят 3–4 rare и 1–2 epic, поковаются и rare и epic броней.
- **Регион 3 (ходы 36+):** mostly epic, концентрируются на финальной комплектации для Лорда.

## Городская экономика и магазин

### Торговец Борн — стартовый магазин

Обновляется каждый визит в город. Показывает **4 случайных предмета**:

- 1–2 обычных предмета (всегда есть выбор)
- 1–2 редких (чем дальше в игре, тем выше вероятность)
- 1× в регион: **Тайный товар** (❓) — за рекламу раскрывается epic

**Цена на магазин:** есть ограничение по типу предмета.

```javascript
const priceByType = {
  common_weapon: 35,
  common_armor: 30,
  rare_weapon: 85,
  rare_armor: 80,
  rare_artifact: 90,
  epic_weapon: 160,
  epic_armor: 170,
  epic_artifact: 185
};
```

### Алхимик — улучшение предметов

- **Обычный → Редкий:** 100g или реклама (1× за город)
- **Редкий → Эпический:** 200g или реклама (1× за город)

Предмет при улучшении **теряет имя**, получает новый рандом из pool редкости.

### Лечение в городе

- Полное исцеление отряда: `(40 - average_hp) * 2` золота
  - Пример: все на 50% HP → 20g за полное лечение
- Или за **рекламу** (1 раз за визит)

3. **Регион 2:** уровень 4–5 + mix common+rare.
   - Волна orc_guard × 2 занимает 3–4 раунда? ✓
   - Лечение в городе дорогое, но нужное (50–80g)? ✓

4. **Финал:** уровень 7–8 + epic + несколько rare.
   - Лорд держится 8+ раундов? ✓

### Крайние случаи

- **Игрок грайндит одну локацию:** враги масштабируются вверх → станет слишком сложно → мотивирует двигаться дальше.
- **Игрок игнорирует лут:** отстаёт от парт-power → враги сильнее → может застрять. Решение: добавить подсказку в город («Советуем экипировку улучшить»).
- **Много убийств на одной локации:** золото падает медленнее опыта → герой уровень 8, но в обычном оружии. Решение: позволить перепродать предметы за 50% стоимости.

## Итоговая философия

**Для игрока:**
- Каждый бой даёт прогресс: либо опыт (level up), либо лут, либо золото.
- Предметы находятся достаточно часто, чтобы мотивировать.
- Враги никогда не бывают _совсем_ непомерно сильными — есть шанс выжить и выучиться.

**Для дизайнера (тебя):**
- Одна метрика (partyPower) управляет всем: врагами, лутом, наградами.
- Добавлять нового врага = добавить уровень и скейл-формулу.
- Добавлять перк = выбрать эффект и привязать к ветке.

**Для баланс-инженера (будущих):**
- Если враги слишком сильные → снизить множитель в `scaleEnemy`.
- Если лут редкий → увеличить `lootChance` или добавить дроп.
- Если герои растут слишком медленно → увеличить `xpForBattle` за 10–20%.
