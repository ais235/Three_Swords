# ТЗ на иконки: что нарисовать, каким и куда положить

Дата: 10 сентября 2026. Исполнитель — художник или кодовый агент, не знакомый с
проектом: всё нужное собрано здесь.

Разделов два и они независимы. **Раздел A** — материалы для карточки игры на
Яндекс Играх, без них нельзя опубликоваться. **Раздел B** — иконки внутри игры,
без них можно, но там сейчас есть прямые ошибки: кнопка показывает не то.

---

## A. Материалы карточки игры

### A1. Иконка игры

| | |
|---|---|
| Файл | `artifacts/store/icon-512.png` |
| Размер | 512×512, PNG без прозрачности |
| Что на ней | три клинка — герб отряда: меч, лук, посох |

Требования площадки к размеру уточняются в консоли разработчика при загрузке —
проверить там перед сдачей, документация публичной страницы их не называет.

Что важно:

- Иконка видна размером с ноготь в списке игр. Три предмета — это уже предел
  различимого; мелкие детали, тонкие контуры и текст не читаются вовсе.
- Название на иконку **не наносить**: площадка показывает его подписью рядом,
  а дубль съедает место.
- Палитра — из игры: тёплый тёмный фон `#13100c`, золото `#f0a500`, бронза
  `#967d66`. Полный список в `styles/tokens.css`.
- Стиль — пиксельный, как спрайты героев в `assets/heroes/`. Не глянцевый
  вектор: он не совпадёт ни с одним скриншотом карточки.

### A2. Обложка

| | |
|---|---|
| Файл | `artifacts/store/cover.png` |
| Размер | уточнить в консоли |
| Что на ней | трое героев на фоне леса, силуэт босса позади |

Фон можно взять из игры: `assets/ui/fon.png` — это меню, оно нарисовано именно
для такого кадра. Герои — `assets/heroes/`.

**Ограничение площадки, пункт 5.1.1**: одинаковые промоматериалы в разных играх
запрещены. Обложка должна быть своя, не переиспользованная.

### A3. Скриншоты — уже сделаны

`npm run promo` кладёт в `artifacts/promo/` пять кадров 1920×1080 и ролик.
Перерисовывать не нужно; если понадобится обновить после правок интерфейса —
та же команда.

Требование 5.1.1.2: реальный геймплей занимает не менее 70% кадра. Поэтому кадры
снимаются с живой игры, а не собираются в редакторе, и вьюпорт подобран так,
чтобы игра заполняла кадр без чёрных полей.

## B. Иконки внутри игры

### B1. Как это устроено сейчас

Модуль `src/emoji-icons.js` подменяет эмодзи в тексте пиксельными картинками из
`assets/ui/emoji/`. Сейчас там **16 картинок на 102 символа**, то есть один
рисунок обслуживает десяток разных понятий.

Отдельно есть `assets/ui/icons/` — монохромные силуэты для кнопок навигации,
подключённые CSS-маской. Они в порядке, трогать не нужно.

### B2. Что сломано и уже вырезано

Пять символов интерфейса подменялись картинкой не по смыслу:

| Символ | Показывал | Должен |
|---|---|---|
| `✕` закрыть | **череп** | крестик |
| `✓` готово | кристалл | галочку |
| `☰` меню | книгу | три полосы |
| `❓` неизвестно | глаз | вопрос |
| `⚙` настройки | кристалл | шестерню |

Подмена для них убрана: сейчас рисуется обычный знак. Это честнее неверной
картинки, но иконки для них всё же нужны — см. B3.

### B3. Что нарисовать: интерфейсные знаки

Пять штук, 32×32, пиксельные, монохром или две-три краски из палитры.
Кладутся в `assets/ui/emoji/` рядом с существующими.

| Файл | Что | Куда попадёт |
|---|---|---|
| `close.png` | крестик | кнопка «Закрыть» |
| `check.png` | галочка | «Изучено», «Все здоровы», «Ход завершён» |
| `menu.png` | три горизонтальные полосы | кнопка «Меню» |
| `question.png` | вопросительный знак | неизвестный узел карты, «???» |
| `gear.png` | шестерня | «Настройки» |

После добавления файлов вернуть строки в таблицу `ICONS` в
`src/emoji-icons.js` — там оставлен комментарий с объяснением, почему их сейчас
нет.

### B4. Что нарисовать: существа

Сейчас **кабан, волк, крыса, змея и паук показываются картинкой корней** —
17 разных символов схлопнуты на `roots.png`. В бестиарии и журнале боя это
выглядит как ошибка, потому что это и есть ошибка.

| Файл | Символы, которые он заберёт |
|---|---|
| `beast.png` | 🐗 🐺 (зверь: кабан, волк) |
| `vermin.png` | 🐀 🐍 🕷 (мелкая тварь: крыса, змея, паук) |
| `undead.png` | 🧟 👻 👾 (нежить — сейчас всё это череп) |
| `rock.png` | ⛰ 🪨 (камень — сейчас корни) |

`roots.png` остаётся за растительностью: 🌿 🌱 🌳 🌲 🍄 🥀.

Приоритет по вреду: `coin` (деньги видны постоянно), `people`, `warning`,
`castle`. Остальное — по возможности.

### B6. Требования к рисунку

- **32×32 пикселя**, PNG с прозрачностью. Крупнее не нужно: в тексте они
  выводятся в 20px, и апскейл только мылит.
- **Пиксель-арт**, без сглаживания. Соседние спрайты — `assets/enemies/`,
  `assets/items/`; попадать в них по плотности пикселя и толщине контура.
- **Читаемость силуэта важнее деталей.** Иконка стоит в строке текста рядом с
  буквами высотой 12px. Проверять надо уменьшенной, а не в редакторе.
- **Тёмный контур** обязателен: иконки лежат и на тёмном фоне панели, и на
  светлой деревянной плашке кнопки. Без контура половина сливается.
- Палитра — `styles/tokens.css`. Золото `#f0a500` для ценного, красный
  `#e74c3c` для опасного, зелёный `#2ecc71` для здоровья, синий `#4a9eff`
  для маны.

### B7. Куда класть и что поменять в коде

1. Файлы — в `assets/ui/emoji/`.
2. В `src/emoji-icons.js`, таблица `ICONS`: дописать строки вида
   `'🐗': 'beast',` и убрать эти символы из старых наборов.
3. Больше нигде ничего менять не нужно: упаковщик находит файлы сам, по
   ссылкам из кода.
4. Проверить: `npm test` (13 наборов) и `npm run ya:build` плюс чекер площадки —
   порядок в `docs/YANDEX_CHECKER.md`.

Проверка, что ни одна иконка не потерялась по дороге в архив, уже есть в аудите:
`npm run audit`, пункт «every control icon has a rule behind it».

## Чего делать не нужно

- Перерисовывать `assets/ui/icons/` — монохромные силуэты кнопок навигации
  сделаны и лицензированы (CC BY 3.0, см. `assets/ui/icons/README.md`).
- Перерисовывать рамки и плашки интерфейса — `assets/ui/kit/`, сделано.
- Заменять эмодзи в игровом тексте поголовно. Их около сотни; смысл имеет
  только то, что перечислено выше, где картинка сейчас противоречит слову.
