# common — общие реакции боя

Универсальные звуки, не привязанные к конкретному герою или врагу.

| Файл | Когда играет | Приоритет |
|------|--------------|-----------|
| `hit.mp3` | любое попадание по цели (поверх звука атаки) | обязательно |
| `hit_block.mp3` | броня поглотила весь урон, цель уцелела | опционально |
| `dodge.mp3` | сработал перк/предмет уклонения (Плащ теней) | опционально |
| `critical.mp3` | критический удар (если будет добавлен) | опционально |
| `death.mp3` | юнит погиб (любой) | обязательно |
| `revive.mp3` | сработало воскрешение (Одеяние феникса) | опционально |
| `level_up.mp3` | герой получил уровень после боя | желательно |

Длительность: 100–300 мс. Лучше короткий «удар/треск», без длинного хвоста.
