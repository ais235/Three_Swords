# heroes — атаки и скиллы трёх героев

Один файл = одно действие героя. Имена по схеме `<heroId>_<action>.mp3`,
где `heroId` ∈ `garet`, `alira`, `seris`.

## Гарет (warrior)

| Файл | Что озвучивает | Длительность |
|------|----------------|--------------|
| `garet_melee.mp3` | обычная атака мечом | 200–350 мс |
| `garet_shield_bash.mp3` | скилл «Удар щитом» (металл + оглушение) | 350–500 мс |
| `garet_fire_call.mp3` | скилл «Вызов огня» (AoE поджог вокруг) | 700–1200 мс |
| `garet_berserk.mp3` | ульта «Берсерк» (рык / усиление) | 600–1000 мс |

## Алира (archer)

| Файл | Что озвучивает | Длительность |
|------|----------------|--------------|
| `alira_bow.mp3` | обычный выстрел из лука | 200–350 мс |
| `alira_double_shot.mp3` | скилл «Двойной выстрел» (две стрелы подряд) | 400–600 мс |
| `alira_slow_arrow.mp3` | скилл «Стрела замедления» (ледяная/липкая стрела) | 300–500 мс |
| `alira_arrow_rain.mp3` | ульта «Дождь стрел» (залп AoE) | 800–1500 мс |

## Сэрис (mage)

| Файл | Что озвучивает | Длительность |
|------|----------------|--------------|
| `seris_magic.mp3` | обычная атака посохом / магический разряд | 250–400 мс |
| `seris_fireball.mp3` | «Огненный шар» (взрыв + ударная волна) | 600–1000 мс |
| `seris_freeze.mp3` | «Заморозка» (льдистый удар, скрежет льда) | 500–800 мс |
| `seris_meteor.mp3` | ульта «Метеорит» (падение + большой взрыв) | 1000–2000 мс |

## Опциональные расширения

- `garet_armor_pierce.mp3` — если активен перк «Пробивание брони» (отдельный звон).
- `alira_first_shot.mp3` — особый звук для первого выстрела за раунд (×1.5).
- `seris_mystic_shield.mp3` — звук активации мистического щита.
