# enemies — атаки и способности врагов

Один файл = одно действие конкретного типа врага. Имена по схеме
`<enemyId>_<action>.mp3`. `enemyId` совпадает с константами `ENEMY_IDS`
в `index.html`.

Если делать поэтапно — сначала залей `*_attack.mp3` для всех, а
особые способности (взрывы, лечение, AoE) добавь позже.

## Регион 1

| Файл | Что озвучивает |
|------|----------------|
| `skeleton_attack.mp3` | удар скелета (хруст костей / лёгкий меч) |
| `goblin_archer_attack.mp3` | короткий выстрел гоблина |
| `boar_attack.mp3` | рывок и удар кабана |
| `zombie_attack.mp3` | укус / цепляние зомби |
| `zombie_explosion.mp3` | **взрыв при смерти зомби (5 урона AoE)** |
| `shaman_attack.mp3` | магический заряд шамана |
| `shaman_heal.mp3` | шаман лечит союзника (мягкий «целительный» аккорд) |

## Что можно объединить, если файлов слишком много

- Все «лёгкие ближние удары» (skeleton/zombie/spider/assassin) можно слить в
  один `enemy_melee_light.mp3` — звучит достаточно похоже.
- Все «тяжёлые удары» (boar/orc_guard/dark_knight/fire_titan) — в
  `enemy_melee_heavy.mp3`.
- Тогда файлы по `enemyId` оставить только для уникальных способностей
  (взрывы, лечение, паутина и т.д.).
