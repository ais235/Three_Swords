# ui — клики и состояния боя

Опциональная группа: можно вообще не озвучивать, но эти штрихи делают бой
«сочнее».

| Файл | Когда играет |
|------|--------------|
| `select_unit.mp3` | игрок выбрал героя для хода |
| `move.mp3` | подтверждение хода на клетку |
| `cancel.mp3` | отмена скилла / возврат в режим хода |
| `skill_ready.mp3` | КД скилла закончился (можно использовать снова) |
| `end_turn.mp3` | нажатие «закончить ход» |
| `turn_start_hero.mp3` | начался ход дружественного отряда (опц.) |
| `turn_start_enemy.mp3` | начался ход врагов (опц.) |
| `victory.mp3` | победа в бою (короткий фанфар, 1–2 с) |
| `defeat.mp3` | поражение |

Все звуки UI должны быть **тихими** относительно боевых SFX (−6 dB от хитов),
чтобы не перекрикивать действие.
