# status — звуки наложения статусов

Один файл = звук в момент **наложения** статуса на цель. Статусы из
константы `STATUS` в `index.html`.

| Файл | Когда играет |
|------|--------------|
| `apply_stun.mp3` | цель оглушена (Удар щитом, Громовой молот) |
| `apply_freeze.mp3` | цель заморожена (Сэрис, Ледяной элементаль, Посох ледяного демона) |
| `apply_web.mp3` | паутина — цель пропускает ход (Паук) |
| `apply_poison.mp3` | наложен яд (Клинок яда) |
| `apply_burn.mp3` | наложено горение (огонь Гарета / Сэрис) |
| `apply_slow.mp3` | замедление (Стрела замедления Алиры) |
| `apply_blind.mp3` | ослеплён (если врагом — Тёмный Лорд / некромант) |
| `apply_curse.mp3` | проклятие |
| `apply_berserk.mp3` | ярость (Берсерк Гарета) |

## Тики урона (опционально)

| Файл | Когда играет |
|------|--------------|
| `tick_poison.mp3` | каждый ход, пока действует яд (короткое «капельное» шипение) |
| `tick_burn.mp3` | каждый ход, пока горение тикает |

Длительность: 200–500 мс для наложения, < 200 мс для тиков (иначе будет
утомлять).
