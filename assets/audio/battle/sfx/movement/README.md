# movement — шаги по клеткам боя

Файлы проигрываются движком при перемещении юнита по сетке.

| Файл | Когда играет |
|------|--------------|
| `step_grass.wav` | земля, трава, обычная клетка |
| `step_rock.wav` | камень, гора, форт |
| `step_wood.wav` | лес |
| `step_water.wav` | вода |

Движок выбирает звук по тайлу назначения и проигрывает 1-3 коротких шага в зависимости от расстояния перемещения.
