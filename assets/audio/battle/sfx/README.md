# Боевые звуковые эффекты (SFX)

Корень: `assets/audio/battle/sfx/`. Формат файлов: **`.mp3`** (как у BGM).
Имена файлов — `snake_case`, латиница, без пробелов.

Звуки делятся на 5 групп — по одной подпапке:

| Папка | Что внутри |
|-------|------------|
| `common/` | общие реакции — попадание, смерть, крит, блок |
| `heroes/` | атаки и скиллы Гарета, Алиры, Сэрис |
| `enemies/` | атаки и фишки врагов из бестиария |
| `status/` | звук наложения статуса + тик (яд/горение) |
| `ui/` | действия по полю боя: выбор юнита, ход, победа/поражение |

В каждой подпапке лежит свой `README.md` со списком ожидаемых файлов и
комментариями: что озвучивает каждый файл и в какой момент проигрывается.

## Минимальный «стартовый» набор (если не хочется заполнять всё сразу)

1. `common/hit.mp3` + `common/death.mp3`
2. `heroes/garet_melee.mp3` · `heroes/alira_bow.mp3` · `heroes/seris_magic.mp3`
3. `heroes/seris_fireball.mp3` · `heroes/seris_meteor.mp3` · `heroes/alira_arrow_rain.mp3`
4. `enemies/skeleton_attack.mp3` · `enemies/goblin_archer_attack.mp3`
5. `enemies/zombie_explosion.mp3` · `enemies/suicide_explosion.mp3`
6. Для боссов: `enemies/fire_titan_aoe.mp3` · `enemies/dark_lord_aoe.mp3`

Остальное можно добавлять по мере поступления звуков — игра автоматически
будет использовать новые файлы (после того, как мы подключим SFX к движку).

## Технические рекомендации к самим звукам

- Длительность: 100–600 мс для ударов/выстрелов, до 1.5–2 с для AoE и скиллов.
- Громкость: одинаковая для группы (нормализация ≈ −3 dB).
- Стерео не нужно, моно достаточно — уменьшает размер.
- Если есть «хвост» (реверб) — встроить в файл, не в код.
