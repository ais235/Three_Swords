# Иконки элементов управления — источник и лицензия

## Что здесь лежит

Монохромные силуэты для кнопок навигации. Подключаются в `styles/kit.css` через
CSS-маску (`mask`), а не как картинки: так иконка красится в `currentColor` и
всегда совпадает по цвету с подписью рядом — золотом на плашке, приглушённо на
отключённой кнопке, без второго файла на каждое состояние.

| `bag.svg` | backpack | Delapouite | Рюкзак |

| `swords.svg` | crossed-swords | Lorc | Арсенал, вкладка «Оружие» |

## Что изменено относительно оригинала

CC BY требует обозначить факт переработки. Изменение одно: у каждого файла
**удалён первый `<path>`** — чёрный прямоугольник-подложка, который отдаёт сайт.
CSS-маска работает по альфа-каналу, и непрозрачная подложка сделала бы маску
сплошной, то есть иконка не была бы видна вовсе. Сами контуры не тронуты.

Скачивались по адресу вида
`https://game-icons.net/icons/ffffff/000000/1x1/<автор>/<иконка>.svg`.

## Почему не эмодзи

Раньше в кнопках стояли 🎒 📖 ⚔ 🔭 🪙 🛡 📺. Их рисует шрифт операционной
системы: на каждой машине они выглядят по-своему и не принадлежат никакому
художественному стилю. На деревянной плашке глянцевый розовый рюкзак был самым
заметным «веб»-элементом из оставшихся.

Эмодзи в игровом тексте — журнал боя, описания способностей, тексты событий —
намеренно оставлены: их 89 видов, это содержание, а не интерфейс.
