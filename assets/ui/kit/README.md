# Графика интерфейса — источник и лицензия

## Что здесь лежит

Рисованные элементы интерфейса: рамка панели, деревянная плашка кнопки в двух
состояниях, ячейка и четыре камня редкости. Подключаются через `border-image`
(9-slice) в `styles/kit.css`.

| Файл | Размер | Назначение |
|---|---|---|
| `panel.png` | 82×82 | рамка панелей, карточек, модальных окон |
| `button.png` | 285×56 | кнопка, обычное состояние |
| `button-on.png` | 285×56 | кнопка под курсором и нажатая |
| `slot.png` | 46×46 | ячейка снаряжения |
| `gem-common.png` | 24×24 | камень редкости: обычная |
| `gem-rare.png` | 24×24 | камень редкости: редкая |
| `gem-epic.png` | 24×24 | камень редкости: эпическая |
| `gem-secret.png` | 24×24 | камень редкости: тайная |

## Что изменено относительно оригинала

CC BY требует обозначить факт переработки. Изменения:

1. Элементы **вырезаны** из общего листа `RPG_GUI_v1.png` — набор поставляется как
   конструктор, а не как готовые виджеты. Координаты вырезов замерены по альфа-каналу
   (заливка связных областей), см. `scripts/build-ui-kit.mjs`, константа `MEASURED`.
2. Камни редкости **получены сдвигом тона** золотой заклёпки из того же листа: в
   наборе нет набора из четырёх цветов. Сдвиги: обычная 0°, редкая 200°,
   эпическая 275°, тайная 340°; насыщенность поднята на 35 %.

Пересобрать комплект: `node scripts/build-ui-kit.mjs <путь к RPG_GUI_v1.png>`.
Сам лист в репозитории не хранится — он весит 2,9 МБ, а нужны только эти вырезы.

## Почему не предыдущий набор

До этого использовался пак «Classic RPG GUI» с Unity Asset Store, полученный
владельцем в подарок от сторонней студии. Лицензия Asset Store выдаётся покупателю
и не передаётся третьим лицам, поэтому подаренные файлы прав на публикацию не дают.
Набор заменён целиком; ни одного файла из него в репозитории не осталось.
