# Items & Loot

Папка для всех предметов, оружия, брони и лута в игре.

## Структура

- `weapons/` — оружие: мечи, луки, посохи, кинжалы и т.п.
- `armor/` — броня: шлемы, нагрудники, поножи, плащи, щиты
- `accessories/` — аксессуары: кольца, амулеты, пояса, серьги
- `consumables/` — расходники: зелья, свитки, еда, эликсиры
- `materials/` — ресурсы для крафта: руда, травы, кожа, ткани
- `misc/` — прочее: квестовые предметы, ключи, валюта, сундуки

## Конвенция именования

- Формат: `PNG` с прозрачностью
- Имена: `snake_case`, латиница, без пробелов
- Размер файла иконки: **256×256 px** (единый стандарт; подогнать: `python scripts/normalize_item_icons.py`). UI сам масштабирует под нужный размер с гладким сглаживанием, поэтому крупные исходники дают чёткую картинку и в маленьких, и в крупных местах.
- Префикс по редкости (опционально): `common_`, `rare_`, `epic_`, `legendary_`

### Примеры

```
weapons/iron_sword.png
weapons/legendary_dragonfang.png
armor/leather_helmet.png
consumables/health_potion_small.png
materials/iron_ore.png
misc/quest_ancient_key.png
```
