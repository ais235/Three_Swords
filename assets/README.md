# Assets

Папка для игровых графических ресурсов.

## Структура

- `heroes/` — спрайты главных героев (портреты, анимации, иконки)
- `npc/` — портреты NPC в городе (`born.png` — торговец Борн, `ruta.png` — алхимик Рута, `veira.png` — оракул Вейра)
- `enemies/` — спрайты врагов и боссов
- `tiles/` — тайлы клеток карты и поля боя
- `ui/` — иконки интерфейса, кнопки, рамки, эффекты
- `items/` — оружие, броня, аксессуары, расходники, материалы и прочий лут (см. `items/README.md`)

## Рекомендуемый формат

- Спрайты: `PNG` (с прозрачностью)
- Тайл-сеты: `PNG` (кратно 16/32/64 px)
- Иконки UI: `PNG` или `SVG`
